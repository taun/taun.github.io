Same invention, new claims. This is a continuation of [US 11,128,987](/n/patent-us-11128987/), filed while I was ROAR's CTO.

The idea hasn't changed. An alert from a button or sensor inside a large building hops across a mesh of low-energy, low-cost Bluetooth devices to a gateway and a server. The server knows where the first device that heard it is, so the alert lands on the building's floor plan right where it started.[^claude]
