Wow! When it comes to software development, what a time we live in.

For me, software development has always been more about the outcome than the software. It’s like becoming a carpenter so you can have furniture. The learning and practicing carpentry is secondary to wanting usable furniture. 

I have wanted to do more blogging for years but not so much that I was willing to overcome all the friction to blogging. Both external and internal. I never wanted the blogging platform to be owned by someone else. I have my reasons. I tried hosting my own blogging platform. Starting with the really complicated “it does everything through the web” versions that require special software running 24/7 on a server. 

Like [Plone](https://plone.org). Among all the now obvious issues was, not being able to edit content offline. 

Then I went to [Jekyll](https://jekyllrb.com) on GitHub pages. Now we’re getting somewhere. 

- It was simpler. 
- No big server (except GitHub’s :-). 
- Editable offline
- Future proof due to simple markdown content format and simple files.
