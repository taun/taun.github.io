**November 2022 – October 2023** · New York, NY

- Enhanced reliability for indoor vertical farms and internal developers by building and managing relationships to identify pain points, prioritize solutions, and manage selected project implementations, improving performance of the farm and the developer.
- Reduced software support calls for a single-point-of-failure automated farm production process from a few per week to zero by re-architecting the cloud backend, the onsite client, and the hardware device driver to use an idempotent, pipelined, and layered approach where each layer had well-defined, limited responsibilities, improving system reliability.
- Improved the software development teams’ (~10 developers) code reliability and observability by mentoring the team in functional programming best practices as implemented in Elixir, Phoenix, and LiveView via code reviews, sample implementations, writing and reviewing technical reviews, team discussions, pair programming, developer tooling, and developer experience.
- Developed POCs to show best practices, lead the way for new architectures, and prove concept potential.
