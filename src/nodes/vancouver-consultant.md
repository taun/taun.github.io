**1991 – 1992** · Vancouver, BC

- Designed and built an NMR (Nuclear Magnetic Resonance) pulse programmer for the University Of British Columbia Physics Department. An NMR pulse programmer is a very high precision data acquisition and signal generating system for investigating material properties using Nuclear Magnetic Resonance. Designed and built a system involving high speed (2 Channel x 1 MHz sample rate with no jitter) A/D converters, a PC, serial control output to a pulse generator and real time software written in C++ for the control and user interface. Designed and wrote a macro language interpreter for automating data acquisition. Wrote a TCP/IP terminal server module to allow remote network control of the system. 10 years later, the system is still in use and the customer happy. ([NMR Pulse Programmer Interface](/n/nmr-pulse-programmer/))
- Designed and built a custom 2 plane balancing system for large high precision cylinders rotating at up to 1000 rpm and small pulleys rotating up to 3600 rpm. Integrated a system consisting of accelerometers, motor controls, a reference platform, 2 channel digital FFT signal analyzer, development and production manuals and custom software written in HP Instrument Basic. The old process required hours and a skilled operator. The new process took less than a ½ hr with an unskilled operator and achieved better quality results. The system was still in use 9 years later. ([2 Plane Balancer](/n/two-plane-balancer/))
