**2014 – 2018**

- 1 of 3 partners in Digital Spring LLC, developer of the Daisy Sensor technology.
- Partner in Digital Spring EField technologies. Patented contactless RF based moisture sensing. Responsible for firmware for a MicroChip PIC, production software & hardware for sensor calibration and QA. Commercial version uses the ModBus standard.
- Sole developer & designer of Daisy Sensor iOS app. Designed to be the user interface for the Bluetooth Low Energy (BLE) Daisy soil moisture sensor. Daisy is a patent pending non-contact soil moisture sensor using eField technology. Also measures ambient light and temperature.
- Worked collaboratively with the firmware and hardware team members to achieve the most efficient implementation at all levels.
- CoreData based DB style app with cloud sync.
- ObjC BLE library for managing multiple BLE device connections and states.
- Coarse location api and BLE background processing to ensure BLE data gathering under all conditions.
- CloudKit api for multi-device sync and public database sharing as well as data crowd sourcing.
- Custom UICollectionViewFlowLayout.
- Custom sound effects for certain state transitions such as a water drop sound effect for Daisy connections.
- After 4 years development, production started with 2000 units manufactured in China as of April 2017.
